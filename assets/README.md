# Public visual assets

Original, self-contained SVG artwork prepared for the SHQ Factory public GitHub profile.

- `monogram.svg` — proposed geometric identity mark.
- `hero-dark.svg` / `hero-light.svg` — paired banners for GitHub's color schemes.
- `engineering-motif.svg` — decorative systems illustration.

These files require no external fonts, JavaScript, remote images, third-party visual assets, or tracking endpoints. The monogram is a **design proposal**, not a statement of trademark registration or exclusive rights to a symbol.

Future website use should preserve the same visual proportions and readable color contrast. Any public license or permitted reuse terms require a separate explicit rights-holder decision; a public repository is not, by itself, an open-source license.
